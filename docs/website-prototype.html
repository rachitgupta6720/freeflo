Troubleshooting
Quarantine Bypass
macOS may flag freeflo as "unidentified developer" because it's not signed with an Apple Developer certificate. You can bypass this via Terminal.
Terminal — run this once after download:
# Remove quarantine attribute on the downloaded app
$ xattr -r -d com.apple.quarantine /Applications/freeflo.app

# Optional: verify the attribute was removed
$ xattr /Applications/freeflo.app
